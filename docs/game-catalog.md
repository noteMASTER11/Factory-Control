# Названия и значки объектов

Каталог импортируется из установленной Factorio скриптом `scripts/import-game-localization.ps1` → `import-game-catalog.py`. Он читает только файлы core, base, space-age, quality и elevated-rails; процесс игры и сохранение не используются. В поставку входят готовые JSON и изображения, поэтому импорт во время работы приложения не требуется.

Русские названия берутся из игровых CFG: предметы, сущности, жидкости, рецепты, технологии, оборудование и планеты. Литеральные поля Lua-прототипов нужны для совпадающих имён, ссылок на оригинальные изображения и составных значков. Lua-код не выполняется. Таблицы ингредиентов/результатов не считаются определениями объектов.

В JSON сохранены прежние `prototype.<name>` и добавлены контекстные ключи `prototype.item.<name>`, `prototype.recipe.<name>` и другие. Например, предмет water-barrel — «Вода (бочка)», одноимённый рецепт — «Наполнить бочку (Вода)», empty-water-barrel — «Опустошить бочку (Вода)». Поиск на русском использует оба контекста, возвращая уникальные внутренние идентификаторы.

Составные значки строятся как SVG из оригинальных PNG-слоёв с игровыми tint, scale и shift. Для бочек используются исходная бочка, две маски и цвета base_color/flow_color; для рецептов наполнения/опустошения добавляется знак жидкости в соответствующем углу. PNG включены в SVG как data URI, внешних зависимостей у такого значка нет. Предметы, сущности и рецепты выбирают изображение по контексту; рецепты без отдельного значка наследуют его от основного результата.

Импорт расширил каталог до 2688 ссылок на изображения и 176 значков технологий. В проверенных текущих снимках было 133 разных имени: 16 не имели перевода и 64 не имели значка. После импорта пропусков в этом наборе нет. Значки также появились в списках источников/потребителей энергии, машин обзора, машин и рецептов производства. Составные изображения проверены декодированием в Chromium и сравнением цвета масок разных жидкостей.

Проверки: `tests/game-catalog.cjs`, `tests/browser-game-catalog.cjs`. Отчёты: `docs/evidence/catalog-audit-before.json`, `catalog-audit-after.json`, `browser-game-catalog.json`. Итоговый EXE проверен по хешам распакованных каталогов/модулей и подключению к текущей игре.
