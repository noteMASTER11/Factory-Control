# Оптимизация памяти и CPU — 23 октября 2026

Проверка на текущей большой базе: около 102 тысяч индексированных объектов и 18,2 тысячи запросных сундуков. Процесс Factorio не перезапускался. CRT включён, окно 1154×866 CSS px, DPI 125%, лимит 30 FPS, `game_speed=100`. При проверке пользователь переключал разделы. Карта была перезагружена внутри игры; финальный замер выполнялся после завершения повторной индексации и появления всех подробностей запросов.

## Причины

- Около 9,6 МБ страниц запросов превращались в тысячи изменяемых JSON-деревьев, многократно копировались и пересылались через MCP/HTTP внутри одного EXE.
- Bridge разбирал изменённые файлы чаще, чем Gateway использовал их.
- SQLite сохраняла полные несжатые JSON; очистке и чтению истории не хватало подходящих индексов.
- Графический тракт использовал MSAA для полноэкранных текстурных проходов, сохранял drawing buffer и держал canvas завершённых ASCII-переходов.

## Изменения

1. Порционный разбор страниц через освобождаемые `JsonDocument`, повторное использование небольших словарей, сводка один раз на поколение. Подробности сохраняются в неизменяемом UTF-8; повторные чтения не разбирают их заново.
2. В монолите `ITelemetrySource` передаёт готовые снимки по ссылке. Внешний MCP и подробные HTTP-маршруты сохранены; раздельный Gateway продолжает работать через MCP.
3. Общие интервалы каналов 1–15 секунд ограничивают чтение файлов и опрос. UI по-прежнему получает только дельты; история остальных разделов обрабатывается Worker-ом.
4. Сжатая история Brotli BLOB, чтение старого TEXT, индексы по сессии/времени. Вывод больших массивов идёт порциями, без сплошного многомегабайтного временного буфера. Старый файл SQLite автоматически не уплотняется.
5. Линейная выборка текстуры, разрешение фильтров, кривизна, резкость и эффекты сохранены. Убраны MSAA в текстурных проходах и сохранение drawing buffer. После завершения ASCII и отключения CRT освобождаются соответствующие буферы; повторное включение проверено.

## Измерения

До изменений: за 31,4 с средний суммарный working set процессов — 2212 МиБ, CPU — 2,53% от всех 24 логических процессоров. Основной процесс — 1610 МиБ. Во время диагностики выделения доходили до 666 МБ/с, паузы GC — до 0,48 с/с.

После исправлений, **92,1 с с полным набором данных**:

| Метрика | Результат |
|---|---:|
| Private working set основного процесса | 136 МиБ |
| Private working set всей группы с WebView2 | 369 МиБ |
| CPU всей группы, среднее | 0,58% |
| Сумма working set всех процессов | 808 МиБ |

Private working set соответствует типу памяти, отображаемому на вкладке «Процессы» диспетчера задач. Сумма working set повторно учитывает общие DLL и отличается от этого столбца. Исходный private working set группы на скриншоте пользователя — около 1558 МиБ; это отдельное наблюдение, а не парный инструментальный замер.

Полный HTTP-ответ проверен на **18 212 сундуках / 92 группах запросов**: количество, наличие, доставка, дефицит и число контейнеров совпадают с независимо рассчитанной сводкой. При нападении состав базы продолжал изменяться. Ранний интервал с незавершённой индексацией отдельно помечен как непригодный для финального сравнения.

Точные последовательные замеры, последняя сборка и сравнение пикселей: [performance-2026-10-23.json](evidence/performance-2026-10-23.json). Это измерения на одной базе и коротких интервалах, а не обещание одинаковых значений для всех карт, разрешений и длительности работы.

## Проверки

- 43 теста .NET: сжатая/старая история, полный JSON через отдельный MCP, частота чтения и освобождение портов.
- Тест на 4096 сундуках: первая загрузка менее 12 МиБ выделений, четыре повторных чтения менее 1 МиБ, потоковый вывод менее 256 КиБ. Проверяется равенство подробностей и сводки.
- 31 файл проверок Node, проверки Chromium для переводов/значков, наведения, тревоги и ресурсов CRT.
- Промежуточный MSAA: 0 изменённых каналов из 6 251 076. Конечный контекст без MSAA/preserveDrawingBuffer: 6 каналов различались на 1 градацию; выборка текстуры не менялась.
- При выключенном CRT графические буферы сбрасываются до 1×1, пул пуст; повторное включение и четыре размера окна проверены.
