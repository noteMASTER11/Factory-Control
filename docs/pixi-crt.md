# PixiJS CRT: экспериментальный режим

Обычный запуск через `Factory Control.cmd` использует Pixi. Хост включает CanvasDrawElement только для своего WebView2. При недоступности API остаётся обычный HTML, без скрытого возврата к SVG-искажению. Старый SVG доступен только явно: `scripts/start-desktop.ps1 -SvgFallback`. `-PixiProbe` и дополнительный cmd оставлены как совместимые варианты запуска того же Pixi-режима. Проверенный runtime: Edge WebView2 / Chromium 155. API пока экспериментальный, его интерфейс может меняться.

HTML остаётся настоящим DOM внутри layoutsubtree canvas. Нативный drawElementImage перерисовывает его при изменениях; updateElementGeometry регистрирует области кликов. Второй canvas показывает текстуру через PixiJS 8.22.0 и pixi-filters 6.1.5. PNG/JPEG, html2canvas и копирование снимков через native-канал не используются. Предпочтение WebGL, линейная фильтрация. Текстура динамическая: иначе после ресайза спрайт оставался старого размера и картинка расходилась с кликами.

CRTFilter отвечает за развёртку, зерно и виньетку; RGBSplitFilter — за слабое разделение каналов; ConvolutionFilter — за умеренное повышение резкости. DisplacementFilter использует общую радиальную геометрию и краткие смещения прямоугольных участков. Чересстрочная развёртка, строчные разрывы и бегущая полоса отключены по итогам визуальной проверки: они ухудшали читаемость текста. Сохраняются 2–4 случайных четырёхугольника с перекосом; они используют тот же генератор, что SVG-режим, и смещаются влево-вправо с восстановлением. Глитчи длятся 240 мс раз в 5,5–11 с; при наведении на элементы управления новые импульсы не начинаются. Reduced motion останавливает анимацию. Общего Gaussian blur в этом режиме нет.

Всё выполняется через общий FrameClock 30 FPS; текстура HTML загружается повторно только при изменении DOM/состояния. Время p50Ms/p95Ms в отчёте — время JavaScript и отправки команд, а не полная стоимость GPU. Эффект не читает игру и не меняет расписание коллектора.

Переключение вкладок: 560 мс команд из JSON и 180 мс появления сигнала с раскрытием из центра, затем 350 мс проявления сверху вниз через ASCII-маску. Маска один раз получает уменьшенный растр активного экрана (либо расположение DOM при недоступном чтении холста), сохраняет резкий текст после прохода и работает через общий FrameClock. При ресайзе переход отменяется без остаточной маски. При reduced motion используется короткий статический переход. Во время перехода ввод в содержимое закрыт; навигация остаётся доступной. История обрабатывается вне DOM в worker.

Проверка: `tests/desktop-production-pixi.cjs`, отчёт `docs/evidence/desktop-production-pixi.json`. Настоящие клики, текстовый ввод, select, прокрутка, ресайз, fullscreen/Esc, две плотности UI 1152×864 и 1024×768, скрытые вкладки без DOM-изменений, частота кадров, BIOS, блочные глитчи без развёртки и выключение эффекта. Проверки проводились на втором мониторе с DPI 96; другие сочетания DPI требуют дополнительной проверки.

Сборка vendor-модуля: пакеты в D:/ChatGPT/Tools/PixiCrtProbe (pixi.js@8.22.0, pixi-filters@6.1.5, esbuild@0.25.12), затем `node scripts/build-pixi-vendor.mjs`. MIT-лицензии сохранены в Web/vfx/vendor. Никаких CDN во время работы.

Игровые экраны очищены от технических примечаний, сносок, FPS и названия платформы. Краткие вкладки: ОБЗ / ЭНРГ / ПРЗВ / ПОДКЛ; полные названия доступны при наведении. Ограничения измерений перенесены в подсказки и документацию.
