# Локализация

`src/Factorio.Desktop/Web/locales/index.json` содержит список доступных локалей и локаль по умолчанию. Сейчас поставляется `ru-RU`. Все пользовательские подписи, подсказки, aria-label, статусы и сообщения лежат в `ru-RU.json`; значения процесса, пути и игровые данные приходят от Windows/шлюза.

В HTML используются `data-i18n`, `data-i18n-title`, `data-i18n-aria-label`. В динамической вёрстке — `Localization.text(key, values)`. Сообщения форматируются целиком: `"ПРОЦЕССОВ: {processes} | ИСТОЧНИКОВ: {sources}"`, без склеивания частей перевода. Для чисел и времени есть форматтеры `Intl` текущей локали. Все используемые русские символы входят в локальные файлы Iosevka Term Slab.

WPF загружает сообщения из тех же JSON-файлов, встроенных как ресурсы сборки. Поэтому сообщение об ошибке WebView2 доступно даже при отсутствии папки веб-файлов. До загрузки веб-страницы используется локаль по умолчанию из каталога; затем страница передаёт выбранную локаль нативной оболочке сообщением `settings.locale`. Оболочка проверяет код по тому же каталогу и обновляет свой словарь и заголовок.

Чтобы в дальнейшем добавить язык:

1. Создать JSON со всеми ключами русской локали и добавить запись в каталог. Поле `file` задаёт имя файла перевода, `name` — подпись в селекторе на самом языке.
2. Пересобрать приложение: JSON автоматически попадёт в веб-файлы и ресурсы WPF. Веб-страница и нативная оболочка выберут его по каталогу, без нового кода переключения.
3. Проверить переполнение таблиц, доступные названия кнопок, числовые и временные форматы при обоих целевых разрешениях. Идентификаторы API/тем и ключи переводов остаются стабильными.

Селектор уже формируется из каталога, сохраняет выбор в профиле WebView2 и загружает выбранный JSON. Если сохранённый код отсутствует в каталоге, используется локаль по умолчанию. Новые UI-строки должны добавляться в JSON до использования в коде.

Русские названия игровых прототипов также хранятся в JSON. `scripts/import-game-localization.ps1` дополняет отсутствующие ключи из локальных русских файлов установленной игры. Динамические шаблоны Factorio с подстановками пропускаются. Для неизвестного прототипа показывается его исходный идентификатор; ранее заданные переводы не заменяются. Значки ресурсов скопированы из локальной установки Factorio для этой панели.
