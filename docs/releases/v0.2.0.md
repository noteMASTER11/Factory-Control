Релиз с оптимизацией памяти и CPU. Все экраны, CRT-эффекты, звук и лимит 30 FPS сохранены.

### Что изменилось

- Готовые снимки передаются между встроенными Bridge и Gateway по ссылке, без внутренней пересылки больших JSON. Внешний MCP и подробный HTTP API сохранены.
- Частота чтения файлов согласована с интервалами каналов, 1–15 секунд. Подробности запросных сундуков разбираются порционно и повторно используются без копирования JSON-деревьев.
- Новая история SQLite сжимается без потери данных; старые записи продолжают читаться. Добавлены индексы и потоковая запись больших массивов.
- Убраны лишние графические MSAA/drawing buffers; canvas завершённых ASCII-переходов и отключённого CRT освобождаются. Линейная выборка текстуры, резкость, кривизна и глитчи сохранены.
- Версия EXE, интерфейса и Gateway — **0.2.0**.

### Результат проверки

На большой базе с примерно 102 тысячами объектов и 18,2 тысячи запросных сундуков, при включённом CRT: средний private working set всей группы с WebView2 — **369 МиБ**, основного процесса — **136 МиБ**; CPU всей группы — **0,58%** от 24 логических процессоров. Финальный замер длился 92 секунды после полной индексации. На исходном скриншоте группа занимала около 1558 МиБ; значения зависят от базы, разрешения и режима работы.

Полный API проверен на 18 212 сундуках и 92 группах запросов. Прошли 43 теста .NET, 31 файл проверок Node и четыре браузерных сценария, включая освобождение/повторное создание CRT-буферов. [Отчёт и методика](https://github.com/noteMASTER11/Factory-Control/blob/v0.2.0/docs/performance-2026-10-23.md).

### Обновление и файлы

Для уже настроенного приложения закройте его и замените **FactoryControl.exe**. **Мод Factory Telemetry остаётся версии 0.4.0; переустанавливать его не требуется.**

Для новой установки скачайте EXE, `factory-telemetry_0.4.0.zip` и `Install-FactoryControl.ps1` в одну папку на D:, затем выполните установку по [README](https://github.com/noteMASTER11/Factory-Control/blob/v0.2.0/README.md#установка). `SHA256SUMS.txt` содержит контрольные суммы.

Требуются Windows x64, Factorio 2.0.77+, диск D: и Microsoft Edge WebView2 Runtime. .NET включён в EXE. Для установщика нужен PowerShell 7.
